Capstone 1: Business Analysis with SQL and Excel

Project Overview

This project focuses on analyzing sales data for EmporiUm for the Maryland territory, a fictional retail business. The goal is to use SQL and Excel to understand sales performance in the Maryland territory and provide recommendations for improving revenue in future quarters.

Tools Used
- **MySQL Workbench:** Used SQL queries to retrieve, filter, and analyze sales data.
- **Microsoft Excel:** Used PivotTables and PivotCharts to organize and visualize sales results.
- **GitHub:** Used to manage and document project files and progress.

Business Questions

The analysis focuses on answering the following questions:

1. What is the total revenue in Maryland, and what period does the data cover?
2. How does revenue break down by year and month?
3. How does Maryland's revenue compare to its region?
4. How many transactions occur each month, and what is the average transaction amount by product category?
5. Which Maryland stores generate the highest revenue?
6. Where should management focus its sales efforts for the next quarter?

Project Files

- `alcantar_sales_analysis.sql` – SQL queries used to analyze Maryland sales performance.
- `alcantar_territory_chart.xlsx` – Excel workbook containing sales analysis and PivotChart visualizations.

Key Takeaway

The purpose of this project is to use sales data to identify business trends, compare store performance, and find opportunities to increase revenue. The findings will help management make better decisions about sales strategies and prepare for upcoming quarters.
